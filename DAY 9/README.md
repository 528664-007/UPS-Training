Day 9 – Java Constructors Tasks
Overview
This folder contains nine Java programs designed to practise constructors, object initialization, methods, and basic object-oriented programming (OOP) concepts.

Programs and Concepts
1. Book.java
Concept: Parameterized Constructor

Initializes book details such as title, author, and price when a Book object is created. Demonstrates how constructors assign initial values to instance variables.

2. Calculator.java
Concept: Constructor and Methods

Initializes two numbers using a parameterized constructor and performs arithmetic operations such as addition, subtraction, multiplication, and division. Demonstrates how object data can be used by instance methods.

3. Child.java
Concept: Constructor and Object Initialization

Uses a parameterized constructor to initialize a child's name and age. Demonstrates how an object's fields can be initialized at the time of object creation.

4. Dog.java
Concept: No-Argument Constructor

Uses a no-argument constructor to assign initial values to a dog's name and breed. Demonstrates how an object can be initialized without passing arguments.

5. Employee.java
Concept: Parameterized Constructor

Initializes employee details, including employee ID, name, and salary. Demonstrates initializing multiple instance variables through constructor parameters.

6. Main.java
Concept: Constructor Overloading

Defines both a no-argument constructor and a parameterized constructor. Demonstrates how Java selects a constructor based on the arguments supplied during object creation.

7. Mobile.java
Concept: Parameterized Constructor

Initializes mobile phone details, including brand, model, and price. Demonstrates how different objects can store different values using the same class structure.

8. Student.java
Concept: Constructor-Based Initialization

Initializes student information such as roll number, name, and marks using a parameterized constructor. Demonstrates how constructors simplify object initialization.

9. Studentnew.java
Concept: Constructor Overloading

Defines two constructors to initialize student objects in different ways: with default values or with user-specified details. Demonstrates multiple constructors within the same class.

Key Java Concepts Practised
Constructors: Special class members that initialize objects when they are created.
No-argument constructors: Constructors that accept no parameters.
Parameterized constructors: Constructors that receive arguments to initialize object fields.
Constructor overloading: Defining multiple constructors with different parameter lists.
Objects: Instances of classes created using the new keyword.
Instance variables: Variables that store data belonging to individual objects.
this keyword: Refers to the current object and helps distinguish instance variables from parameters.
Instance methods: Methods that operate on an object's fields.
Object initialization: Assigning initial values to an object's data when it is created.
Conclusion
These programs provide practical experience with Java constructors and object creation. They demonstrate how constructors initialize object data, how constructor overloading supports different initialization options, and how methods access and display object information. These concepts form an important foundation for object-oriented programming in Java.
